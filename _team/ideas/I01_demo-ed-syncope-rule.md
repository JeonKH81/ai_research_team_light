# I01 응급실 실신 위험점수는 실제 진료에서 어떻게 쓰이는가

|------|------|
| 단계 | gap-verified |
| 생성일 | 2026-08-27 |
| 최종 갱신 | 2026-09-06 |

| 필요 데이터 | 응급실 방문 기록, 퇴실 판정, 30일 재방문 (본보기 — 실제 자료 아님) |

> **본보기 카드다.** 내용은 전부 지어냈다. 연습이 끝나면 지우고 자기 후보를 넣는다.

## 연구 질문
응급실 실신 환자에서 위험점수가 산출된 뒤에도 입원 결정이 점수와 어긋나는 비율은 얼마이며, 어긋난 쪽의 30일 결과는 다른가?

## 왜 이 질문인가
위험점수는 "얼마나 잘 맞히는가"로만 평가돼 왔다. 실제로 그 점수가 결정을 바꿨는지는 별개의 질문이고,
바꾸지 않았다면 정확도가 아무리 높아도 진료는 그대로다.

## 선행연구 지형 (검색 2026-09-02 · 본보기)

| 이미 답한 것 | 근거 |
|---|---|
| 여러 실신 위험점수의 판별력 비교 | 다기관 검증 연구 다수 (본보기 — 실제 인용 아님) |
| 점수를 쓰면 불필요한 입원이 준다 | 중재연구 1건 (본보기 — 실제 인용 아님) |
| **점수와 실제 결정이 어긋난 환자는 누구인가** | **없음** |

## 갭 검증
- 판정: **부분공백**
- 공백 유형: **미탐색** (정확도는 포화, 결정 반영은 비어 있다)

## 가설
점수가 저위험을 가리켰는데도 입원한 군은 고령·동반질환이 몰려 있으며, 30일 결과는 저위험 퇴실군과 다르지 않다.
