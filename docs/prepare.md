# 실습 전 준비 — 오기 전에 끝내 오세요 (15분)

> **이것이 안 돼 있으면 실습에 참여할 수 없습니다.** 당일 현장에서 하면 한 시간이 다 갑니다.
> 막히면 **전날까지** 연락 주세요.

준비는 셋입니다. **① Claude 를 쓸 창 ② Python ③ 연구실 폴더.**

---

## ① Claude 를 쓸 창 — 셋 중 **하나만** 고릅니다

유료 Claude 계정(Pro·Max·Team·Enterprise)이 있어야 합니다. **무료 계정으로는 안 됩니다.**

### 길 A — Claude 앱 (가장 쉬움, 터미널 없음) ◀ 권장

1. 앱을 받아 설치합니다.
   - 맥: https://claude.ai/download
   - 윈도우: https://claude.com/download
2. 앱을 열고 유료 계정으로 로그인합니다.
3. 왼쪽에서 **Code** 탭을 누릅니다. 이 탭이 보이면 준비 끝입니다.

### 길 B — VS Code (평소 VS Code 를 쓰는 분)

1. VS Code 를 설치합니다: https://code.visualstudio.com
2. VS Code 를 열고 `Cmd+Shift+X`(맥) 또는 `Ctrl+Shift+X`(윈도우) 를 누릅니다.
3. **Claude Code** 를 검색해, 만든 곳이 **Anthropic** 인 것을 **설치**합니다.
4. 왼쪽 막대의 Claude 아이콘을 눌러 창을 열고 유료 계정으로 로그인합니다.

이 확장은 필요한 것을 안에 품고 있어 **따로 더 설치할 것이 없습니다.**

### 길 C — 터미널 (평소 터미널을 쓰는 분만)

맥 터미널:
```bash
curl -fsSL https://claude.ai/install.sh | bash
```

윈도우 PowerShell (`PS C:\...>` 로 시작하는 창):
```powershell
irm https://claude.ai/install.ps1 | iex
```

설치 뒤 **창을 새로 열고** 확인합니다:
```
claude --version
```
버전 번호가 나오면 됩니다. 이어서 `claude` 를 한 번 실행하면 브라우저가 열립니다. 거기서 유료 계정으로 로그인합니다.

## ② Python 3.9 이상

연구실의 현황판·보고·문헌 수집이 Python 으로 돕니다.

**맥:** 대개 이미 있습니다. 터미널에서 `python3 --version` 을 쳐서 숫자가 나오면 끝입니다.

**윈도우:** 거의 없습니다. https://www.python.org/downloads/ 에서 받아 설치하되,
설치 첫 화면의 **`Add python.exe to PATH`** 를 **반드시 켜고** 설치합니다. 이걸 놓치면 나중에 아무것도 안 됩니다.
설치 뒤 PowerShell 에서 `python --version` 으로 확인합니다.

## ③ 연구실 폴더 받아 두기

1. https://github.com/JeonKH81/ai_research_team_light 을 엽니다.
2. 초록색 **Code** 단추 → **Download ZIP**.
3. 받은 파일의 압축을 풉니다. `ai_research_team_light-main` 폴더가 생깁니다.
4. 그 폴더를 **바탕화면**처럼 찾기 쉬운 곳에 둡니다.

## 확인 — 여기까지 됐는지 스스로 봅니다

고른 길대로 창을 열고, **③에서 받은 폴더를 연 다음**, 창에 이렇게 칩니다:

```
설치 확인을 돌려서 결과를 보여 줘.
```

폴더 여는 법은 길마다 다릅니다.
- **길 A(앱):** Code 탭 → **Select folder** → 그 폴더
- **길 B(VS Code):** 파일 → 폴더 열기 → 그 폴더 → 왼쪽 Claude 아이콘
- **길 C(터미널):** 그 폴더로 옮겨 가서 `claude`

**✓ 가 줄줄이 뜨고 마지막에 "설치는 정상" 이라고 나오면 준비 끝입니다.**
`✗` 가 있으면 그 줄 옆에 고치는 방법이 같이 나옵니다. 그대로 해 보고, 안 되면 그 화면을 찍어 보내 주세요.

## 잘 막히는 곳

| 증상 | 뜻과 대처 |
|---|---|
| 앱에 **Code** 탭이 안 보인다 | 앱이 오래됐습니다. 앱을 최신으로 다시 받습니다 |
| 로그인이 안 된다 | 무료 계정입니다. 유료 계정(Pro 이상)이 있어야 합니다 |
| 윈도우에서 `python` 을 모른다고 한다 | 설치할 때 `Add python.exe to PATH` 를 안 켠 것입니다. 다시 설치하며 켭니다 |
| 윈도우에서 `irm ... not recognized` | PowerShell 이 아니라 명령 프롬프트입니다. 창 맨 앞이 `PS C:\` 인지 봅니다 |
| 받기·설치가 중간에 끊긴다 | 병원망이 막는 경우입니다. 집이나 휴대폰 테더링으로 해 봅니다 |
| 압축을 풀면 한글 이름이 깨진다 | 이 폴더에는 한글 파일 이름이 없습니다. 다른 파일을 푼 것인지 확인합니다 |
