# 실습 전 준비 — 오기 전에 끝내 오세요 (15분)

> **이것이 안 돼 있으면 실습에 참여할 수 없습니다.** 당일 현장에서 하면 한 시간이 다 갑니다.
> 막히면 **전날까지** 연락 주세요.

준비는 셋입니다. **① Claude 를 쓸 창 ② Python ③ 연구실 폴더.**

---

## ① Claude 를 쓸 창 — 셋 중 **하나만** 고릅니다

유료 Claude 계정(Pro·Max·Team·Enterprise)이 있어야 합니다. **무료 계정으로는 안 됩니다.**

### 길 A — VS Code ◀ 권장 (확인된 길)

1. VS Code 를 설치합니다: https://code.visualstudio.com
2. VS Code 를 열고 `Cmd+Shift+X`(맥) 또는 `Ctrl+Shift+X`(윈도우) 를 누릅니다.
3. **Claude Code** 를 검색해, 만든 곳이 **Anthropic** 인 것을 **설치**합니다.
4. 왼쪽 막대의 Claude 아이콘을 눌러 창을 열고 유료 계정으로 로그인합니다.

이 확장은 필요한 것을 안에 품고 있어 **따로 더 설치할 것이 없습니다.** 터미널도 필요 없습니다.

### 길 B — 터미널 (평소 터미널을 쓰는 분)

맥 터미널:
```bash
curl -fsSL https://claude.ai/install.sh | bash
```

윈도우 PowerShell (`PS C:\...>` 로 시작하는 창):
```powershell
irm https://claude.ai/install.ps1 | iex
```

설치 뒤 **창을 새로 열고** 확인합니다:
```
claude --version
```
버전 번호가 나오면 됩니다. 이어서 `claude` 를 한 번 실행하면 브라우저가 열립니다. 거기서 유료 계정으로 로그인합니다.

### 길 C — Claude 앱의 Code 탭 (권하지 않습니다)

앱에도 **Code** 탭이 있어 폴더를 열 수 있습니다. 다만 **이 연구실로는 시험해 보지 않았고, 앱 판에서 `/setup` 같은 것이 목록에 안 뜨는 일이 실제로 있었습니다.**
앱으로 하시겠다면 실습 전에 반드시 한 번 돌려 보고, 안 되면 길 A 로 옮기세요.

## ② Python 3.9 이상

현황판·보고·문헌 수집이 Python 으로 돕니다. **맥은 대개 이미 있습니다.**

**맥:** 터미널에서 `python3 --version` 을 쳐서 숫자가 나오면 끝입니다.

**윈도우:** 거의 없습니다. PowerShell 을 열고 **한 줄**이면 됩니다:

```powershell
winget install Python.Python.3.12
```

이 방법은 PATH 를 알아서 잡아 줍니다. 설치가 끝나면 **PowerShell 창을 닫았다 새로 열고** 확인합니다:

```powershell
python --version
```

`winget` 을 모른다고 하면 [python.org](https://www.python.org/downloads/) 에서 받아 설치하되,
설치 첫 화면의 **`Add python.exe to PATH`** 를 **반드시 켜고** 설치합니다.

> **깔지 못했어도 실습에 오세요.** Python 이 없으면 총괄팀장이 대신 처리하도록 해 두었습니다.
> 문헌 자동 수집 한 가지만 그날 빠집니다.

## 확인 — 여기까지 됐는지 스스로 봅니다

고른 길대로 창을 열고, **③에서 받은 폴더를 연 다음**, 창에 이렇게 칩니다:

```
설치 확인을 돌려서 결과를 보여 줘.
```

폴더 여는 법은 길마다 다릅니다.
- **길 A(VS Code):** 파일 → 폴더 열기 → 그 폴더 → 왼쪽 Claude 아이콘
- **길 B(터미널):** 그 폴더로 옮겨 가서 `claude`
- **길 C(앱):** Code 탭 → 폴더 선택

**✓ 가 줄줄이 뜨고 마지막에 "설치는 정상" 이라고 나오면 준비 끝입니다.**
`✗` 가 있으면 그 줄 옆에 고치는 방법이 같이 나옵니다. 그대로 해 보고, 안 되면 그 화면을 찍어 보내 주세요.

## 잘 막히는 곳

| 증상 | 뜻과 대처 |
|---|---|
| 앱에서 `/setup` 같은 것이 목록에 없다 | 앱 판의 알려진 문제입니다. **길 A(VS Code)로 옮기세요** |
| 앱에 **Code** 탭이 안 보인다 | 앱이 오래됐습니다. 최신으로 다시 받거나 길 A 로 옮깁니다 |
| 로그인이 안 된다 | 무료 계정입니다. 유료 계정(Pro 이상)이 있어야 합니다 |
| 윈도우에서 `python` 을 모른다고 한다 | 창을 닫았다 새로 여세요. 그래도 안 되면 `winget install Python.Python.3.12` 로 다시 깝니다. **못 깔아도 실습은 됩니다** |
| 윈도우에서 `irm ... not recognized` | PowerShell 이 아니라 명령 프롬프트입니다. 창 맨 앞이 `PS C:\` 인지 봅니다 |
| 받기·설치가 중간에 끊긴다 | 병원망이 막는 경우입니다. 집이나 휴대폰 테더링으로 해 봅니다 |
| 압축을 풀면 한글 이름이 깨진다 | 이 폴더에는 한글 파일 이름이 없습니다. 다른 파일을 푼 것인지 확인합니다 |
